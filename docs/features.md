# Features

Padel Mix & Match is a mobile-first PWA for running a club evening on
one phone — no accounts, no server, offline after the first load.

Edit this file on GitHub when marketing copy or capabilities change.
The welcome / About tagline lives separately in
[`about-tagline.txt`](./about-tagline.txt) (bundled at build time).

## Session setup

- Add players (up to 80 on the roster; typical evenings use 4–16).
- **Points per game** — preset 16 / 24 / 32 or a custom even value
  (6–98).
- **Courts** — 1–12; the generator uses as many as players allow.
- **Tournament format** — Americano (random fair rotation), Mexicano
  (courts by ranking), or Mix Americano (mixed M+F teams).
- **Avoid same partners** — optional toggle for back-to-back rounds.
- Change settings before or during a session (future rounds only).

## During play

- Generate rounds, enter scores per court, live ranking.
- Sum-to-target scoring (both teams add up to your chosen points total).
- Swap any player (playing or resting) before a score is saved.
- Re-shuffle the current round before any score is saved.
- Manual **Add game** from History for missed matches.
- **Final round** — seeded from the leaderboard (Points or Wins mode).

## Players

- Rename, pause, or mark as left mid-session.
- **Mix Americano** — set M/F per player on the Players tab.
- Manual bonus points on the Ranking tab.

## Share & handoff

- **Copy session** — compressed share code for any messenger.
- **Import session** — paste on another phone; supports chunked codes.
- Everything stays on-device unless you choose to share.

## Appearance

- Dark and light theme (Settings / Session).
- Blue Lions translucent LCD design.
- Installable PWA with offline support and auto-update banner.

## For hosts

- One phone is the source of truth — use Copy session to hand off.
- Reload app to pick up new versions without losing data.
- Feedback via **Session → About → Send feedback** (GitHub issue).
